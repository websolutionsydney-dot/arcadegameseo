- Organization, WebSite, WebPage, Service and breadcrumb structured data; service data includes all seven stated enquiry regions. No fake address, phone, reviews, prices or Product offers in schema.
- Visible FAQs, descriptive native links, section anchors and related-service links. FAQ rich-result eligibility is not claimed.

- Compressed WebP images, server-rendered page architecture and mobile navigation retained. Image dimensions are specified to reserve layout space. The six locally served font files now use WOFF, reducing their combined size from 366,824 to 190,536 bytes (48.1%) without changing the typefaces.
